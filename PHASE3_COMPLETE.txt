================================================================================
                        HOW IT WORKS
================================================================================

DATA FLOW:
  Firebase Services → Providers (State) → Screens (UI)

REAL-TIME:
  Firestore Update → Provider Stream → notifyListeners() → UI Rebuilds

USER ACTIONS:
  Tap Button → Provider Method → Firebase Operation → State Update → UI

ERROR HANDLING:
  Error Occurs → Provider.errorMessage Set → Consumer Rebuilds → Error Shows
